**PrepPath Studio** is an AI-powered video, graphic, and caption generation engine designed to create high-converting Instagram Reels, Stories, and Carousels that promote **PrepPath AI** to secondary school applicants, parents, and educational consultants.

---

## 🌟 Key Features

### 🎬 1. 60 FPS HTML5 Canvas Video Engine (`VideoCanvas.tsx`)
- **Real-Time 60 FPS Animation Engine:** Renders dynamic kinetic typography, floating particles, glowing badges, particle confetti bursts, and score counters directly in the browser.
- **Multi-Format Aspect Ratios:** Toggle between **9:16 Instagram Reels / Stories**, **1:1 Square Posts**, and **4:5 Portrait Carousels**.
- **Browser Video Export:** Uses the `MediaRecorder` API to export `.WEBM` video reels and `.PNG` story graphics with zero server rendering overhead.

### 🎨 2. High-Converting Template Presets (`TemplateSelector.tsx`)
- 🎓 **"Official Acceptance" Reel:** Animated acceptance letter reveal with particle confetti, school badge, and SSAT score card.
- 🧠 **"99th Percentile SSAT Hack" Reel:** Kinetic question walkthroughs with countdown timer.
- ⚔️ **"Peddie vs Andover vs Exeter Matrix" Reel:** Side-by-side boarding school stat cards (Endowment, SSAT, Culture).
- ✍️ **"Essay Transformer" Reel:** Line-by-line essay transformation with +24% acceptance odds boost.
- 🎙️ **"Mock Interview Simulator" Reel:** Interactive AI interviewer question reel.

### 🧠 3. Smartest AI Caption & Hashtag Engine (`CaptionPanel.tsx`)
- **Persona Target Switcher:** Generates viral hooks, body copy, and CTAs tailored for **Students / Applicants** vs **Parents & Families**.
- **Optimal Posting Window Predictor:** Analyzes engagement data to suggest peak posting times (e.g. *7:45 PM EST*).
- **Estimated Reach Estimator:** Predicts expected organic video plays (e.g. *14.8K – 32.5K Plays*).
- **Hashtag Stack Builder:** Auto-generates niche-targeted hashtag bundles (#BoardingSchoolAdmissions #SSATPrep #PrepPathAI).

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start local dev server (runs on http://localhost:3002)
npm run dev

# Build for production
npm run build
```
